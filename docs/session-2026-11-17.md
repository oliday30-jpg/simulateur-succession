## 1. Demande initiale (résumé fidèle)

Construire en VS Code un simulateur familial **local et privé, en français**, pour comparer donation / vente / maintien,
avec valeurs à confirmer par le notaire, l'expert et les banques. Pas de déploiement, compte, serveur, clé API ni IA intégrée
(contrainte levée ensuite pour GitHub Pages, à la demande de l'utilisateur). Aucune action juridique ou financière réelle.
Exigences principales : rôles anonymes renommables dans le navigateur ; valeurs distinctes (ancienne, hypothèse, expertise, au 07/10/2026,
à la date de l'événement) ; lots fractionnaires ; quart du fils prédécédé jamais certain ; créance non ajoutée par défaut ;
legs ≠ sortie du vivant ; risque de double versement don + legs ; 7 questions ; modèles en un clic ; au moins 3 variantes ;
référence alignée ; événements datés et ordonnés ; seuils 3/5 ans (anniversaire, bissextile, jours voisins, enregistrement distinct) ;
modes de bilan A/B ; budget ; vente avec coefficient d'usufruit saisi (test : 300 000 €, 15 % fictif → 172 500 / 45 000 / écart 127 500) ;
moteur fiscal versionné vérifié sur les sources ; restitution (statuts, détail dépliable, matrice de sensibilité, impression, JSON, CSV,
fiche notaire) ; Vite + TS + React ; centimes ; dates civiles ; schéma + migrations ; tests + parcours interface ; README.

## 6. Décisions et raisons

Voir CLAUDE.md § « Décisions importantes ». Compléments :
- Barème « en vigueur » limité aux décès jusqu'au 31/12/2027 (art. 30 du décret 2024).
- Base d'une donation avec réserve d'usufruit = pleine propriété du lot donné (conforme à votre repère 4 500 € ; pratique à confirmer).
- Combinaisons d'hypothèses limitées à 64 ; hypothèse « prudente » affichée en détail (logement non éligible, rappel et réserve appliqués).
- Valeurs par défaut : décès simulé 30/11/2027, actes 15/12/2026, logement « hypothèse éligible », réserve « inconnue », droits mobiliers payés par le père, droits immobiliers et frais d'acte payés par le fils.
- Accès iPhone : options présentées — A pages privées claude.ai (sync, données chez Anthropic), B réseau privé type Tailscale (données chez soi, machine allumée, déconseillé sur PC pro), C GitHub Pages (données sur l'appareil, pas de sync). **C retenu** : usage principal sur iPhone, confidentialité, gratuité.

```python
import sys
from PIL import Image, ImageDraw, ImageFont
out = sys.argv[1]; S = 1024; BG = (11, 92, 173, 255); W = (255, 255, 255, 255)
def draw(full_bleed):
    img = Image.new('RGBA', (S, S), BG if full_bleed else (0, 0, 0, 0)); d = ImageDraw.Draw(img)
    if not full_bleed: d.rounded_rectangle([0, 0, S - 1, S - 1], radius=220, fill=BG)
    cx = S // 2
    d.polygon([(cx, 250), (cx + 300, 500), (cx - 300, 500)], fill=W)
    d.rectangle([cx - 230, 480, cx + 230, 780], fill=W)
    d.rounded_rectangle([cx - 60, 620, cx + 60, 780], radius=20, fill=BG)
    try: f = ImageFont.truetype('arialbd.ttf', 170)
    except OSError: f = ImageFont.load_default()
    d.text((cx, 545), '€', font=f, fill=BG, anchor='mm')
    return img
base = draw(True)
for size, name in [(180, 'apple-touch-icon.png'), (192, 'icon-192.png'), (512, 'icon-512.png')]:
    base.resize((size, size), Image.LANCZOS).convert('RGB').save(f'{out}/{name}', optimize=True)
draw(False).resize((64, 64), Image.LANCZOS).save(f'{out}/favicon.png', optimize=True)
```

## 11. Points à faire valider par le notaire

1. Réserve de progressivité (existence, durée, imputation de l'exemption, art. 66bis).
2. Taux réduit logement : éligibilité, départ en maison de soins, empilement avec le reste (art. 60ter).
3. Exemption pour le petit-fils légataire ; traitement d'un don rappelé au petit-fils.
4. Jour exact de bascule des délais de 3 et 5 ans ; enregistrement tardif ou distinct du don.
5. Base des droits d'une donation avec réserve d'usufruit ; cumul ; devis des frais d'acte.
6. Règle applicable aux décès dès 2028 (décret voté vs réforme annoncée, exonération de 75 000 €).
7. Vente : coefficient d'usufruit convenu, accords, quart du fils prédécédé, report d'usufruit.
8. Titres, testament, valeur actuelle et au 07/10/2026, créance (solde, montant recouvrable, traitement fiscal).
